## 发布新版本

1. 把当前的 `CLA.en.md`、`CLA.zh-CN.md` 复制到 `archive/v<旧版本>/`；
2. 修改当前文件的版本号、生效日期、权利人（如变更）；
3. 更新本页的版本表；
4. 如变更权利人，在 `TRANSFERS.md` 追加一行，并提前 7 天公告。

当前版本不复制进归档，归档只放被取代的版本。
