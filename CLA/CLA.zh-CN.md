# 贡献者许可协议（CLA）· 中文译本

**版本 1.0**
**生效日期：** 2026 年 11 月 25 日
**项目权利人：** ImJingLan（GitHub：@ImJingLan）

> **语言。** 本中文译本仅供参考，英文正式文本见 [CLA.en.md](CLA.en.md)。如中英文版本存在任何冲突，以英文版本为准。

本贡献者许可协议（“本协议”）由您（“您”或“贡献者”）与上栏所列的项目权利人（“权利人”）订立，适用于您向项目提交的全部贡献。

您通过向项目提交贡献（包括创建 Pull Request 或在 Issue 中发布代码）即接受本协议。您的提交构成具有约束力的电子接受。如 Pull Request 模板包含同意勾选框，勾选该框用于记录您的接受，但并非本协议生效的条件。

## 1. 定义

1.1 “项目”指 KyokkouPT 组织在 GitHub 上的仓库，包括但不限于 backend 与 frontend 仓库，以及权利人指定为项目组成部分的其他仓库。

1.2 “权利人”指上栏所列的项目权利人，以及依据第 8 条受让权利的任何承继方。

1.3 “贡献”指您向项目提交的任何代码、文档、设计或其他材料，包括 Issue 或 Pull Request 中的代码片段。

1.4 “生效版本”指您提交该贡献时，依据第 9 条发布并生效的本协议版本。

1.5 “承继方”指权利人依据第 8 条向其转让本协议的任何个人、公司、基金会或其他主体。

## 2. 著作权许可

2.1 您保留对您贡献的著作权中的全部权利、所有权和利益。本协议不转让您的著作权。

2.2 您授予权利人及其承继方一项永久的、全球范围的、非独占的、免许可费的、不可撤销的许可，并有权再许可，以：

(a) 使用、复制、修改、制作衍生作品、公开展示、公开表演、分发及以其他方式利用您的贡献及其衍生作品；

(b) 以任何条款许可和分发您的贡献，包括 GNU 通用公共许可证第 3.0 版或更新版本、Apache 许可证第 2.0 版，以及商业或专有许可条款；

(c) 通过多层再被许可方再许可上述任何权利。

## 3. 专利许可

3.1 您授予权利人、其承继方及项目分发软件的接收方一项永久的、全球范围的、非独占的、免许可费的、不可撤销的专利许可，以制造、委托制造、使用、要约出售、出售、进口及以其他方式转移您的贡献；该许可仅适用于您有权许可、且仅因您的贡献或您的贡献与项目的结合而必然被侵犯的专利权利要求。

3.2 如果您对任何主体提起专利诉讼（包括诉讼中的交叉请求或反诉），主张项目或并入项目的贡献构成直接或帮助专利侵权，则您根据本协议就该等项目授予的任何专利许可自该诉讼提起之日起终止。

## 4. 陈述与保证

您陈述并保证：

(a) 每项贡献均为您的原创，或您已取得授予本协议所述许可的充分权利；

(b) 据您所知，每项贡献不侵犯或盗用任何第三方的著作权、专利、商标、商业秘密或其他知识产权或专有权利；

(c) 如您的雇主对某项贡献享有或可能享有权利，您已获得代表该雇主提交该贡献的许可，或该雇主已放弃相关权利；

(d) 每项贡献不包含您无权按本协议条款提交的任何第三方代码或材料。

## 5. 免责声明

除适用法律要求或书面同意外，您按“现状”提供您的贡献，不附带任何明示或默示的保证，包括但不限于对所有权、不侵权、适销性或特定用途适用性的任何保证或条件。

## 6. 署名

6.1 项目将在提交记录及贡献中包含的著作权声明中保留您的署名。

6.2 您同意，权利人及其承继方行使第 2 条授予的权利时，通过提交记录署名即为充分，您不要求在其他分发中单独标注您的姓名。

## 7. 版本与更新

7.1 权利人可不时修订本协议。每次修订将以新的版本号和生效日期标识，旧版本归档到 `CLA/archive/` 目录。

7.2 生效版本适用于每项贡献。

7.3 修订仅适用于生效日期当日或之后提交的贡献。此前提交的贡献仍适用其提交时有效的版本。

## 8. 权利转移

8.1 权利人可以将本协议及项下全部权利和义务整体转让给任何个人、公司、基金会或其他主体，无需您另行同意。您提交贡献即视为不可撤销地同意该等转让。

8.2 权利人应在转让生效前至少七（7）日在项目仓库公告转让意向，并发布标明承继方与生效日期的新版本协议。转让自该生效日期起生效。

8.3 对于生效日期之前提交的贡献，本协议项下已授予的全部权利自生效日期起自动、不可撤销地转由承继方享有；原权利人不再享有该等权利。

8.4 生效日期当日或之后提交的贡献，视为直接授予承继方。

8.5 转让不影响已发布版本所适用的开源许可证，包括 GPL-3.0-or-later 和 Apache-2.0。

## 9. 发布位置与迁移

9.1 本协议在 KyokkouPT 的 `.github` 仓库发布，适用于项目的全部仓库，不在各仓库分别维护副本。

9.2 权利人可以将本协议迁移至其他仓库、网站或其他位置。

9.3 权利人应在迁移前至少七（7）日在 `.github` 仓库公告。迁移后，新位置发布的版本为唯一有效版本，原位置应保留指向新位置的说明。

9.4 迁移不影响已授予的许可。每项贡献仍适用其提交时有效的版本，无论该版本发布于何处。

## 10. 其他

10.1 **完整协议。** 本协议构成您与权利人之间就贡献达成的完整协议，并取代此前就此达成的任何协议。

10.2 **可分割性。** 本协议任何条款被认定无效或不可执行的，其余条款仍具有完全效力。

10.3 **不放弃。** 权利人未执行本协议任何条款，不构成对该条款日后执行权利的放弃。

10.4 **无使用义务。** 权利人没有义务使用、合并或分发任何贡献。

10.5 **您的转让。** 未经权利人事先书面同意，您不得转让本协议。

10.6 **适用法律。** 本协议适用中华人民共和国法律以及您提交贡献时所在国家或地区的法律，并依其解释。上述法律存在冲突的，以中华人民共和国法律为准；但您所在国家或地区法律中不能通过协议排除的强制性规定除外。

10.7 **语言。** 本协议以英文订立。中文译本仅供参考；如中英文版本存在任何冲突，以英文版本为准。
